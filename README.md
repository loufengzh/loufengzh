## In the spotlight

### [Foliohush](https://github.com/loufengzh/foliohush)

A quiet, local-first writing desk built with React and TypeScript. Browser-local drafts, named snapshots, and portable JSON, Markdown, and HTML exports.

### [Nameproof Kit](https://github.com/loufengzh/nameproof-kit)

Turn a product idea into a reasoned shortlist. A Python CLI and portable agent skill for domain observations, country-specific trademark evidence, and a clear record of what remains unknown. Evidence screening, not legal clearance.

**[Read a real example report ↗](https://github.com/loufengzh/nameproof-kit/blob/main/examples/report.md)** · [Agent setup](https://github.com/loufengzh/nameproof-kit/blob/main/docs/INSTALL.md) · [Source & guide](https://github.com/loufengzh/nameproof-kit#readme)
