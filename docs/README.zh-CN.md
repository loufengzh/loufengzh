## 精选项目

### [Foliohush](https://github.com/loufengzh/foliohush)

用 React 和 TypeScript 构建的安静、本地优先的写作空间。草稿保存在浏览器本地，支持命名快照，以及便于迁移的 JSON、Markdown 和 HTML 导出。

**[打开在线演示 ↗](https://loufengzh.github.io/foliohush/)** · [源码与指南](https://github.com/loufengzh/foliohush#readme) · [移动端视图](https://github.com/loufengzh/foliohush/blob/main/docs/screenshots/mobile.png)

### [Nameproof Kit](https://github.com/loufengzh/nameproof-kit)

把产品想法转化为有依据的命名候选清单。提供 Python 命令行工具和可移植的智能体技能，用于收集域名观测结果、特定国家的商标证据，并清楚记录尚未确认的信息。仅用于证据初筛，不构成法律上的可用性确认。

**[阅读真实示例报告 ↗](https://github.com/loufengzh/nameproof-kit/blob/main/examples/report.md)** · [智能体配置](https://github.com/loufengzh/nameproof-kit/blob/main/docs/INSTALL.md) · [源码与指南](https://github.com/loufengzh/nameproof-kit#readme)
