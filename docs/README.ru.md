## Избранные проекты

### [Foliohush](https://github.com/loufengzh/foliohush)

Спокойное пространство для письма на React и TypeScript с приоритетом локального хранения. Черновики в браузере, именованные снимки версий и переносимый экспорт в JSON, Markdown и HTML.

### [Nameproof Kit](https://github.com/loufengzh/nameproof-kit)

От идеи продукта к обоснованному короткому списку названий. CLI на Python и переносимый навык для агента: наблюдения о доменах, сведения о товарных знаках по странам и ясная фиксация того, что ещё неизвестно. Предварительная проверка сведений, а не юридическое заключение о допустимости использования.

**[Прочитать реальный пример отчёта ↗](https://github.com/loufengzh/nameproof-kit/blob/main/examples/report.md)** · [Настройка агента](https://github.com/loufengzh/nameproof-kit/blob/main/docs/INSTALL.md) · [Код и руководство](https://github.com/loufengzh/nameproof-kit#readme)
