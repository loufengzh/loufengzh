### [Foliohush](https://github.com/loufengzh/foliohush)

Ein ruhiger Schreibplatz nach dem Local-first-Prinzip, entwickelt mit React und TypeScript. Entwürfe lokal im Browser, benannte Versionsstände und portable Exporte in JSON, Markdown und HTML.

### [Nameproof Kit](https://github.com/loufengzh/nameproof-kit)

Von der Produktidee zur begründeten Namensauswahl. Ein Python-CLI und ein portabler Agent-Skill für Beobachtungen zu Domains, länderspezifische Markenbelege und eine klare Dokumentation offener Fragen. Eine Vorprüfung der Belege, keine rechtliche Freigabe.

**[Einen echten Beispielbericht lesen ↗](https://github.com/loufengzh/nameproof-kit/blob/main/examples/report.md)** · [Agent-Einrichtung](https://github.com/loufengzh/nameproof-kit/blob/main/docs/INSTALL.md) · [Quellcode und Anleitung](https://github.com/loufengzh/nameproof-kit#readme)
